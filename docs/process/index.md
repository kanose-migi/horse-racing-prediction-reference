# Process

各ページでは同じフォーマットで、競馬分野と他分野からの転用候補を並べて確認します。

## Standard format

1. **目的** — この工程が解く問題
2. **入力 / 出力** — 前後工程との境界
3. **競馬分野のアプローチ** — 既存研究・実装で利用される方法
4. **他分野からの転用候補** — まだ競馬で一般化していない方法
5. **評価観点** — 何をもって有効とするか
6. **注意点** — leakage、calibration、market efficiency等
7. **関連ページ / Sources**

工程一覧は [Home](../index.md) の Technology map を参照してください。
