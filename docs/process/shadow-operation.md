# D2. Shadow Operation

## 目的

実際のデータ到着・締切・オッズ変動を使って予測と意思決定を生成しつつ、実購入せず記録します。

## 競馬分野のアプローチ

- paper / virtual betting
- live prediction log
- 推奨時オッズと最終オッズの比較
- 実績との事後照合

## 他分野からの転用候補

- shadow deployment
- champion / challenger
- canary evaluation
- production observability

## 評価観点

offline backtestとの差、データ欠落、latency、odds drift、prediction drift。
