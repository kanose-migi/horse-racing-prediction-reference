# C. Decision

## Goal

予測された確率や順位を、実際の行動へ変換します。

## Processes

1. [Uncertainty / Selection](../process/uncertainty-selection.md)
2. [Ticket Probability](../process/ticket-probability.md)
3. [Decision Optimization](../process/decision-optimization.md)
4. [Bankroll / Risk](../process/bankroll-risk.md)

## Key idea

予測精度と意思決定品質は別問題です。競馬外ではSelective Prediction、Conformal Risk Control、Decision-Focused Learning、Robust Optimizationなど、**予測後の判断**を直接扱う研究が発展しています。
