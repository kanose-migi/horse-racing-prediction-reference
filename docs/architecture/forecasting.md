# B. Forecasting

## Goal

馬の能力、着順、確率、市場評価など、将来の状態を予測します。

## Processes

1. [Fundamental Prediction](../process/fundamental-prediction.md)
2. [Ranking](../process/ranking.md)
3. [Probability Calibration](../process/probability-calibration.md)
4. [Market Modeling](../process/market-modeling.md)

## Key idea

「最も順位を当てるモデル」「最も校正された確率を出すモデル」「市場価格を最もよく予測するモデル」は同一とは限りません。Ranking scoreとbetting probabilityを区別し、Fundamental modelとMarket modelも分離して比較できる形が望まれます。
